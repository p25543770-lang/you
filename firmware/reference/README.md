# Эталон: скетч руля, проверенный на железе

`steering_tested/steering_tested.ino` — мастер-скетч руля, который владелец
робота проверил на своей механике (TB6600 на D6/D7/D8, оптодатчик на D18,
133.33 шага/°, 100 мкс на шаг). Файл лежит **без изменений** — как эталон, с
которым сверяется прошивка `motor_master`/`motor_node` (руль v2).

Что из него взято и что доработано — в `firmware/README.md`, раздел «Что
изменилось». Тест `tests/test_firmware.py` проверяет, что пины, уровни и
скорости v2 совпадают с этим скетчем.

Загружать этот скетч вместе с прошивкой v2 не нужно: он не выдаёт телеметрию
`@TLM`, и бортовой экран с ним не работает.
